# ADR-002: Выбор решения для генерации прайс-листов по расписанию

 <a name="_hjk0fkfyohdk"></a>**Автор: Максимов Артем**
## 1. Контекст

Каждое утро ровно в шесть онлайн-магазину нужно сгенерировать кастомные CSV/XLS-прайс-листы для B2B-клиентов на основе текущих данных в БД.
Процесс выгрузки не требует дополнительной логики по обработке данных.

Данные в PostgreSQL представлены в таблицах:

- products ~ 5 000–10 000 строк;
- categories ~ 50–200 строк;
- clients ~ 100–500 строк;
- client_prices ~ 10 000–20 000 строк.
## 2. Требования

Необходимо связать данные из таблиц и выгрузить их в CSV-файл. Объём данных 5 000–10 000 строк.
Инфраструктура магазина — микросервисы в облаке.

## 3.  Критерии выбора решения

Для сравнения технологических решений были выбраны следующие критерии:

1. Наличие конфигурации CRON-расписания
2. Сложность реализации логики по обработке данных
3. Ресурсоёмкость решения (количество потребляемых ресурсов
4. Масштабируемость решения под нагрузкой и сложность реализации
5. Сложность развёртывания в облаке и интеграция с имеющейся микросервисной архитектурой
6. Удобство интеграции с системами логирования и мониторинга

## 5.  Решение

Для описанного сценария больше всего подходит K8s Job по следующим причинам:

- Задача простая  
    Нужно один раз в день выполнить SQL-запросы, связать данные из четырех таблиц  и выгрузить результат в CSV. Сложной бизнес-логики, ветвлений, зависимых пайплайнов и распределённой обработки нет.
- Небольшой объём данных  
    5 000–10 000 строк — это объём, который спокойно обрабатывается одним контейнером
- Инфраструктура уже в Kubernetes  
    Магазин работает как набор микросервисов в облаке
- Решение легко мониторить и сопровождать  
    Job пишет структурированные логи в stdout/stderr, Kubernetes хранит статус выполнения, Prometheus/Grafana могут собирать метрики


Альтернативы решают поставленную задачу, но слишком громоздки для ее небольших объемов. Они требуют лишних ресурсов, экспертизы и переусложняют решение за счет необходимости реализовывать свои окружения
